## 재생성 방법

코드가 바뀐 뒤 보고서를 갱신하려면 다음 순서로 다시 감사합니다.

1. 백엔드 저장소에서 `**/controller/*Controller.java`의 `@*Mapping` 어노테이션을 모두 뽑아 엔드포인트
   목록(55개)을 만듭니다. 백엔드 저장소는 참고용으로만 읽고 수정하지 않습니다.
2. 프론트 `src/api/*.js`의 함수와 대조해 매핑 여부를 확인하고, 각 함수 이름을 `src/` 전체에서
   grep 해 실제 호출 컴포넌트/페이지를 기록합니다. 함수만 있고 호출이 없는 것은 "미연동"입니다.
3. `src/data/*.js`의 `MOCK_*`/`FALLBACK_*`/`SAMPLE_*` 상수와 그 import 위치, 클릭해도 API를 부르지
   않는 버튼(`onClick`이 토스트·닫기만 하는 경우), 존재하지 않는 라우트로 가는 `<Link>`를 찾아
   하드코딩·목업·빈 동작 인벤토리를 갱신합니다.
4. 백엔드 요청/응답 DTO(`**/dto/*.java`)와 비교해 프론트 UI가 있는데 필드/API가 없는 항목을
   "백엔드에 없어서 막힌 것"에 정리합니다.
5. 같은 파일 경로에 결과를 덮어쓰고, 헤더의 생성 일시·기준 커밋을 갱신합니다.

홈 중심 보고서(`api-integration-report.html`)는 Codex 감사 프롬프트로 생성했습니다. 원본 프롬프트는
이 작업을 지시한 팀 리드 메시지(2026-09-11 API 연동 감사) 기록을 참고하세요.
