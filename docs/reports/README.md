# API 연동 감사 보고서

`api-integration-report.html`은 Travel Tackle 프론트엔드가 백엔드(Spring Boot) API 55개
엔드포인트 중 무엇을, 어디서(특히 홈 화면) 실제로 호출하고 있는지 정리한 자체 완결형(inline
CSS/JS, 외부 요청 없음) HTML 보고서입니다. 엔드포인트별 사용 여부·화면 위치·연동 상태
(연동완료/부분연동/미연동)와 함께 부족한 점, 우선순위별 권장 작업, 백엔드 요청 목록을 담고
있습니다. 브라우저로 바로 열어 확인할 수 있습니다.

## 재생성 방법

브랜치를 최신 `origin/develop` 기준으로 다시 비교하고 싶거나 코드가 바뀐 뒤 보고서를
갱신하려면, Codex에게 다음 감사 프롬프트를 다시 실행시키면 됩니다.

1. 프론트엔드 저장소에서 대상 브랜치로 이동 후 `git diff origin/develop..HEAD`로 변경 범위를
   확인합니다.
2. `src/api/*.js`(API 클라이언트 함수)와 백엔드 저장소의 `**/controller/*Controller.java`를
   대조해 엔드포인트별 매핑 여부와 사용 컴포넌트/페이지를 다시 확인합니다.
3. 이 문서와 같은 위치(`docs/reports/api-integration-report.html`)에 결과를 덮어씁니다.

백엔드 저장소는 참고용으로만 읽고 수정하지 않습니다. 정확한 원본 프롬프트는 이 작업을
지시한 팀 리드 메시지(2026-09-11 API 연동 감사) 기록을 참고하세요.
