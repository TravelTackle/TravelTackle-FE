한 줄 결론

데이터 흐름은 거의 다 실제 API다. 남은 문제는 "가짜 데이터"보다 "있는 API를 안 쓰는 것"과 "없는 API를 프론트가 대신 계산하는 것" 두 종류로 좁혀졌다. 아래 우선순위 작업 목록의 HIGH 5건이 사용자에게 바로 보이는 구멍이다.
